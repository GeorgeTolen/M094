# М094 — пробный тест

Интерактивный тест по материалам пробного тестирования М094.

- **[index.html](index.html)** — сайт-тест: 17 вариантов на двух языках, выбор ответов, подсчёт баллов по правилам экзамена, разбор ошибок. Один файл, всё внутри — можно открыть локально или отдать GitHub Pages.
- **[QUESTIONS.md](QUESTIONS.md)** — все 420 вопросов с вариантами и отмеченными правильными ответами.
- **[data/](data/)** — исходные сканы в JSON (`db1–db7`, `alg1–alg6`, `kzdb1–kzdb2`, `kzalg1–kzalg2`), из них собран сайт.

## Подсчёт баллов

**База данных** — один или несколько правильных ответов (не более трёх):

| Ситуация | Баллы |
|---|---|
| правильный один, отмечен только он | 2 |
| правильный один, отмечено несколько | 0 |
| правильных несколько, отмечена часть без ошибок | 1 |
| правильных несколько, отмечены все | 2 |
| отмечен хотя бы один неправильный | 0 |

**Алгоритмы и структуры данных** — один правильный ответ, 1 балл за верный.

## Режимы

- **Язык** — переключатель 🇷🇺 Русский / 🇰🇿 Қазақша на главной.
- **Экзамен** — ответы и баллы показываются в конце.
- **Тренировка** — правильный ответ подсвечивается сразу.
- **Перемешать вопросы** — случайный порядок.

Управление с клавиатуры: `←` / `→` — переход между вопросами, буква варианта или цифра `1–9` — выбор ответа.

## Публикация на GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`. Сайт появится по адресу `https://<user>.github.io/M094/`.

## Оговорка

Тексты вопросов и вариантов считаны со скриншотов теста. **Правильные ответы в источниках не отмечены** — они проставлены по предмету, поэтому отдельные ответы могут быть неверными.

В казахских скриншотах галочки проставлены тем, кто проходил тест, и **эталоном не являются** — ответы там пересчитаны заново (например, в одном вопросе отмечено `a--`, тогда как префиксный декремент — `--a`).

12 вопросов, где ответ объективно неоднозначен (например, верных вариантов больше трёх, а тест допускает максимум три), помечены ⚠ — в сайте пометка видна в разборе ответов, в [QUESTIONS.md](QUESTIONS.md) — под вопросом. Их стоит сверить с преподавателем.
